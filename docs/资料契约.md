# 资料契约

所有记录均为本地合成演练资料，不含真实个人、企业或医疗信息。文件使用 UTF-8 JSON，金额和数量以各字段说明为准。空串、零、缺报、争议分别保留其含义，不可互相替换。

记录的 `id` 只在本资料类别内唯一。`known`、`known_day`、`known_week`、`known_month` 表示收到事实的时间；实际发生时间另有字段。日序和分钟是演练的相对时间，未另行说明的区间均左闭右开。月份为演练年度的自然月。

`data/schema.json` 声明字段、类型和显式引用。数组与对象内的业务关系按相应中文字段说明解释；资料检查器不替代这些业务关系的判断。原始与后补记录共存，文件排列不代表业务生效顺序。

## entrances

入口属性含有效区间；宽度厘米。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 入口 |
| `width_cm` | number | 净宽 |
| `steps` | integer | 台阶数 |
| `lit` | boolean | 照明 |
| `start` | string | 有效开始 |
| `end` | string | 有效结束 |

## panels

匿名小组；同意范围可能缩小。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 小组 |
| `mode` | string | 方式 |
| `weight` | number | 抽样权重 |
| `habit` | string | 原使用频率 |
| `consent` | string | 内部及公开或仅内部 |
| `withdrawn` | string | 停止后续日期或空 |

## journeys

无出行与未报告分开；时长为分钟。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 出行记录 |
| `group` | string | 小组 |
| `day` | string | 出行日 |
| `origin` | string | 起点区 |
| `destination` | string | 终点区 |
| `entrances` | array | 实际入口 |
| `minutes` | number | 记录分钟 |
| `state` | string | 完成或放弃或未出行或未报告 |
| `reason` | string | 原因 |

显式引用：`group` → `panels.id`。

## counter_windows

入口分时计数不是独立受访者数量。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 窗口 |
| `entrance` | string | 入口 |
| `day` | string | 日 |
| `slot` | string | 时段 |
| `count` | integer | 计数 |
| `online` | boolean | 设备在线 |

显式引用：`entrance` → `entrances.id`。

## reviews

现场复查对开放或出行事实提出更正。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 复查 |
| `target` | string | 目标 |
| `kind` | string | 对象类别 |
| `finding` | string | 核实事实 |
| `known` | string | 获知日 |

## assessments

已有公布范围属于真实管理承诺。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 管理决定 |
| `entrance` | string | 入口 |
| `state` | string | 已公布或备选 |
| `promise` | string | 承诺 |
| `effective` | string | 生效日 |

显式引用：`entrance` → `entrances.id`。

## rules

演练调查与通行约定。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 配置 |
| `wheelchair_width_cm` | number | 轮椅最低净宽 |
| `stroller_width_cm` | number | 童车最低净宽 |
| `public_min_groups` | integer | 公开最小独立小组数 |
| `max_completion_drop` | number | 完成比例保护界限 |
